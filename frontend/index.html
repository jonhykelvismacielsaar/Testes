API rápida (curl)

curl -X POST http://localhost:3900/api/generate \
  -H "Content-Type: application/json" \
  -d '{"text":"Olá mundo","voice":"pt-BR-FranciscaNeural"}'

# OpenAI-compat
curl http://localhost:3900/v1/audio/speech \
  -H "Content-Type: application/json" \
  -d '{"model":"tts-1","input":"Hello!","voice":"alloy"}'
